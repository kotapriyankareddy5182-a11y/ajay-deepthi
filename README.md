# Ajay & Deepthi Engagement Invitation

Image 1 is used exactly as supplied. The only overlay on Image 1 is the **Open Invitation** button, positioned below the existing Ajay & Deepthi names.

After clicking the button:
1. Image 1 closes.
2. The remaining five invitation images appear in order.
3. Automatic scrolling starts.
4. The pause/resume and back-to-top controls are available.
